# Raven Revenue Engine

Raven Revenue Engine moves commercial prioritisation into the collector itself so every downstream interface reads the same intelligence.

Each discovered lead now carries:

- commercial_score
- tier (T1, T2, WATCH)
- next_action
- evidence_confidence
- estimated_fee_gbp
- repeat_signal

The feed also contains a summary with Raven Found, Tier 1, Tier 2, potential fee pipeline and source health.

The fee pipeline is an opportunity indicator, not booked or guaranteed revenue. Every lead still requires verification, buyer fit, fee protection and Kevin's approval before external release.
